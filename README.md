# Meshbreakers

Phone dice-kit roguelike. Humans, cyborgs, and allied machines vs a hostile robot mesh.

## How to play

1. Tap **New run**.
2. Pick a starter.
3. Tap a die, then tap a target.
4. Tap **COMMIT**.

Paste seed **DAKOTA7** on the title screen to replay a known layout.
